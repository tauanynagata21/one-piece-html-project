# One Piece HTML Project

Projeto desenvolvido no início do aprendizado em desenvolvimento web utilizando HTML.

## Sobre o projeto
Site informativo sobre o anime One Piece, contendo páginas individuais para personagens e uma página com lista de aberturas do anime.

## Funcionalidades
- Múltiplas páginas HTML
- Navegação entre páginas
- Links externos para vídeos no YouTube
- Organização de conteúdo informativo

## Tecnologias utilizadas
- HTML5

## Observação
Projeto desenvolvido durante as primeiras aulas de programação web para prática de estruturação de páginas e navegação entre arquivos.
